# マロン価値観1 家編

部屋選びで大切にしている価値観を、暮らしの悩みとともに紹介する会社発表用のプレゼンテーションです。

「部屋選びで、暮らしは変えられる」をテーマに、静かさ・広さ・回線環境の3つの視点から、自分に合う住まいについて考えます。

## 主な内容

- **静かさ**：騒音や振動を踏まえた建物選び
- **広さ**：趣味のものを置ける、自分に合った部屋の広さ
- **回線環境**：遅延とアップロード速度が暮らしに与える影響
- **測定結果の比較**：FAST.comの画面を使った回線A・回線Bの比較

## この資料について

- 発表者：マロン
- 想定発表時間：約5分
- スライド数：26枚（待機画面・表紙・最後の挨拶を含む）
- 補足説明や参考URLは、PowerPointの発表者ノートに記載しています。

部屋の広さなどの条件には、個人の経験や好みを含みます。建物の構造や間取りだけで住み心地が決まるわけではありません。

回線の比較は、それぞれの測定時点での結果です。測定条件が同一とは確認できないため、通信事業者や配線方式の優劣を断定するものではありません。
